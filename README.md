# 🌐 Connectra

**Connectra** is a full-stack developer networking platform that enables professionals to connect, showcase their technical skills, and discover like-minded collaborators. It combines intelligent skill-based matching, networking features, and premium memberships to build a focused ecosystem for developers.

---

## 🚀 Live Demo

- 🔗 **Frontend:** https://connectra-rose.vercel.app  
- ⚙️ **Backend:** https://connectra-backend-ohw6.onrender.com  

---

## ✨ Key Features

### 🔍 Smart Developer Discovery
- Intelligent skill-based matching using Fuse.js
- Enables users to discover relevant developers based on tech stack

### 🤝 Professional Networking
- Send and manage connection requests
- Explore a dynamic feed of developer profiles
- Build and grow your professional network

### 💳 Premium Memberships
- Tiered plans: Starter, Pro, Enterprise
- Secure payment integration using Razorpay

### 🛠️ Tech Stack Showcase
- Add and manage technical skills
- Improve profile visibility and discoverability

### 🛡️ Secure Authentication
- JWT-based authentication system
- Cookie-based session management
- Protected routes using middleware

### 📄 Dynamic User Profiles
- Personalized user profiles
- Displays skills, connections, and user activity

---

## 🧩 System Architecture

- RESTful API-based architecture
- Frontend communicates with backend via Axios
- Backend handles authentication, business logic, and database operations
- MongoDB stores user data, connections, and skills
- JWT stored in cookies for session handling

---

## 🔐 Authentication Flow
Users sign up or log in using credentials
Backend generates JWT token
Token is stored in cookies
Protected routes validate user via middleware
Logout clears authentication cookie
